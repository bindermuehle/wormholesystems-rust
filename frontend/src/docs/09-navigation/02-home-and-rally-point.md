# Home & rally point

Two kinds of shared markers, home systems and up to two rally points per map, help a group orient around the chain. Both are **broadcast in real time** — set or change one and it updates instantly on every member's map.

## Home system

Set a **home system** to mark your staging or tower system. It's shown with a home indicator on the map and acts as the anchor your group measures from — including as the starting point for the rally route below. Pair it with a [pin](/documentation/organizing-your-map/pinning-and-ignore-list) so it's never cleaned up.

A map can have **more than one home**. If you run two chains that don't touch, say your own hole and a staging system somewhere else, mark both: each is the root of its own chain, and each chain is [numbered on its own](/documentation/bookmarking/let-the-mapper-name-it), so both have a `1`. Setting another home never replaces one you already have; clear a home from its right-click menu.

## Rally point

Drop a **rally point** when you need the group to converge somewhere — forming up, responding to a fight, or staging for a roam. A map can hold **two rally points** at once, for example a form-up spot and the fight itself. Rally systems stand out on the map with a pink glow and tint, and each one gets its own badge in the top right that names the system and counts the jumps **from home to that rally point** (the nearest home, if there are several), so everyone reads the same number rather than each measuring from where they happen to be. Click the count to see the route it counted.

Setting a third rally point replaces the oldest one. Clear a single rally point from its right-click menu when the moment's over; the other one stays.

Because both markers are shared live, a called rally reaches the whole fleet at the same instant — no ambiguity about where to meet.
